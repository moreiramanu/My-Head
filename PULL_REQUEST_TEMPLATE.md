## Objetivo
Personalizar a página inicial do projeto "My Head", ajustando conteúdo, estilos visuais e organizando melhor a estrutura de arquivos.

- Deixar a página com identidade própria, com frase de destaque personalizada
- Melhorar a organização do código separando o CSS do HTML
- Adicionar um efeito visual (estrela cadente) para tornar a página mais dinâmica

## Mudanças
- Estrutura do index.html alterada e nova frase de destaque adicionada, dando mais personalidade e identidade à página
- CSS separado em arquivo externo (css/style.css)
- Efeito de estrela cadente adicionado ao fundo animado, deixando a página mais dinâmica e visualmente interessante
- Frase de destaque alterada novamente para refinar a mensagem exibida na página

## Como testar
- Clonar o repositório e abrir o arquivo `index.html` no navegador (ou usar a extensão Live Server no VS Code)
- Verificar se o fundo com gradiente escuro, as estrelas e a lua estão aparecendo corretamente
- Observar se o efeito de estrela cadente aparece cruzando a tela periodicamente
- Conferir se a frase de destaque exibida no centro da página está correta e legível
- Verificar no console do navegador (F12) se não há nenhum erro sendo exibido
- Confirmar que o CSS está sendo carregado corretamente a partir do arquivo `css/style.css`
